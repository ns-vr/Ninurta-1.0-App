## 🪶 What Even Is This

Ninurta is what happens when you give a mildly caffeinated developer a Gemini API key, six hours, and a deep personal vendetta against every teacher who ever said *"you're just not applying yourself."*

It is, technically, **16 AI-powered tools duct-taped into one dashboard.** It is also, spiritually, a shrine to the idea that studying should feel like a video game and not like emotional damage.

Named after the Mesopotamian god of wisdom, farming, healing, and war — because apparently ancient civilizations already knew that learning is a battle, and we just gave that battle a leaderboard.

## 🏛️ Tech Stack (a.k.a. What We Yelled At Until It Worked)

- **Frontend:** React + Tailwind, held together by hope and `useState`
- **AI Brain:** Gemini 2.5 Flash for the easy stuff, Gemini 2.5 Pro for when we need it to *really think about it*
- **Voice:** Web Speech API, because Gemini Live was too powerful for our WiFi
- **Maps:** Google Maps API, so Location Scout doesn't just recommend the same imaginary library
- **Persistence:** localStorage, the duct tape of data storage
- **Design Philosophy:** dark mode, gold accents, and the unshakable belief that every button should feel like pressing "Continue" in a JRPG

## 🚀 Getting Started

```bash
git clone https://github.com/your-team/ninurta.git
cd ninurta
npm install        # this will take longer than your last exam prep
npm run dev        # pray to Ninurta himself
```

Then open `localhost:3000` and begin your transformation from "person who has 47 browser tabs open" into "person who has 47 browser tabs open, one of which is Ninurta."
